# Icon sources

Generated by `tools/fetch_icons.py` (run `python -I tools/fetch_icons.py` from the repository root). Every source is pinned,
so a rerun gives the same files. Every SVG is checked for DOCTYPE/ENTITY, then rebuilt from an allowlist of elements and
attributes: no scripts, event handlers, external references or foreignObject survive.

Logos and product names are trademarks of their owners. They are used only to name the products in diagrams.

Project licences (for the Open source pack) were read from each project's repository on 2026-11-20 (GitHub licence API, and
the licence file where GitHub said "Other"). Each product's licence is in `manifest.json`.

Agreement 1.1, April 2026), MongoDB (SSPL v1), OpenFaaS CE (Community Edition EULA). Redis is listed under its AGPLv3 option.
