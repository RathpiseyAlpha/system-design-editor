Archboard design system

Draw cloud systems as 3D blocks on a grid, or type them as text. Built for GICI5CC students; free for anyone.

3D canvas Diagram as code AWS and open source

Direction

  • Blocks on drafting paperServices are isometric blocks standing on a faint diagonal grid; zones are raised floor plates. The 3D is a reading aid, not decoration: depth shows what sits inside what.
  • Ink and pressureEverything you can touch has an ink outline and a hard shadow. Pressing moves it into its shadow. The green highlighter means active: the open view, the primary action, the selection.
  • Role first, product secondA block shows its name, then its product: orders-db over RDS or PostgreSQL. One switch renames the whole diagram; nothing moves.
  • Text and canvas are one diagramThe code view is not an export. Edit either side and the other follows. Errors stay on their line while the canvas keeps the last good state.

Service categories (top, left, right face)

Each category is one colour. The top face mixes in white (--top-mix), the right face mixes in shade (--side-mix), so a new category needs one value.

Type

JetBrains Mono for the whole interface, like a drafting label. IBM Plex Sans only for long text: notes, challenge briefs, help. Both bundled in the app.

Pressure

2px ink outlines; corners of 8 (controls), 14 (panels), round (chips). Shadows have no blur: 2px for controls and chips, 3px for panels, 5px for frames. Hover lifts 1px; press sinks into the shadow.

One primary button per view, verb + object. Delete is the only red control and names what goes.

Palette and fields

A

Search finds a service by role, AWS name or open-source name: "bucket", "s3" and "minio" all find Object storage.

Blocks: states

Blocks: shapes by kind

Shape says the kind of thing, colour says the category: a box runs code, a cylinder keeps data, a low box stores files, a plate is people or devices outside the cloud.

Zones

A VPC or region is a raised plate with a solid outline. Subnets are painted areas on it, dashed, tinted green (public) or violet (private). The tab names the zone and its kind.

Connections

Request: waits for an answer (HTTP, SQL)
Async message: through a queue or topic
Data: replication, backup, sync

Lines run along the two grid axes and turn at right angles, at half block height, so they read as cables between boxes. Labels are pills on the longest straight part. Orange ports appear on a selected block.

What changes on small screens

  • Below 900px the inspector becomes a bottom sheet that opens on selection; below 640px the palette does too, behind Add service.
  • Connect is a button (Connect to, then tap the target), because dragging a port with a finger is unreliable.
  • The code view is read-only below 640px; typing the syntax on a phone keyboard is not a goal.
  • Touch targets are 44px; two-finger pan and pinch zoom; long-press opens the block menu.

Interaction notes

Keyboard

AAdd a service (search) DelDelete the selection Ctrl ZUndo, 100 steps Ctrl DDuplicate ArrowsMove one grid cell along the grid RRotate the view 90 degrees FFit the diagram TabNext block, back to front

Behaviour in 3D

  • Blocks snap to grid cells. Arrow keys move along the two grid axes, which is what a learner expects on an isometric grid.
  • Rotate view turns the camera by 90 degrees so a block hidden behind another can be reached; the file does not change.
  • Flat view shows the same file from above, for dense diagrams and for printing.
  • Nothing blocks: a hint is a flag and a pill on the block and a line in the Hints list, never a dialog.
