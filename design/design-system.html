Archboard design system

A 3D editor for the architecture of any system. Draw blocks on a grid or type the diagram as text, then show it as generic roles, AWS services or open-source projects.

3D canvas Diagram as code Any stack, swappable icon packs Laptop to monitor Simulator

Direction

  • Neutral core, swappable packsA diagram is written in generic roles (service, database, queue) and zones (network, subnet, region). An icon pack only renames and re-icons it: Generic, AWS or Open source today, other clouds later. Nothing in the editor assumes one vendor or one course.
  • Blocks on drafting paperServices are isometric blocks with softly rounded edges on a faint diagonal grid; zones are raised floor plates. Depth shows what sits inside what.
  • Real icons, shown as they areEach block carries its product's real icon on a light sticker on its top face: the official AWS icon or the project's own logo, never redrawn, recoloured or skewed.
  • Ink and pressureInk outlines and hard shadows; pressing sinks into the shadow. The green highlighter marks what is active: the open view, the primary action, the selection.
  • Text and canvas are one diagramEdit either side and the other follows. Errors stay on their line while the canvas keeps the last good state.
  • Test it before you build itThe simulator runs spikes, failures and slow parts against the diagram. Blocks fill with load, failed parts switch off, and a plain verdict names what breaks. It is a teaching model with indicative numbers, not a cloud emulator.
  • Fits the screen you haveDesigned at 1280 × 720 first (a 15.6" laptop at 150% scaling) and grows to 1920 × 1080 and beyond: panels narrow, the palette folds into a rail, density tightens on short screens.

Blocks: states

Outer edges are rounded (5px); the corner where three faces meet stays sharp, so the block still reads as a solid.

Blocks: shapes, with real icons

Shape is the kind of thing, colour the category, the sticker the product. A server is a virtual machine or a group of them, a box runs other code, a cylinder keeps data, a low box stores files, a plate is people or devices outside the system.

Zones

Zone kinds are generic (region, network, failure zone, subnet, group). Packs name them: the AWS pack says VPC and Availability Zone and shows its official group icon in the tab.

Connections

Request: waits for an answer
Async message: through a queue or topic
Data: replication, backup, sync

Lines run along the two grid axes at half block height and turn at right angles. Labels are pills on the longest straight part.

The verdict is a plain sentence first, numbers second. "Breaks" names the bottleneck or single point of failure and gives one hint.

Icon packs

Every role in the neutral catalog, with what each pack shows for it. AWS icons come from the official AWS Architecture Icons package (31 July 2026 release), unmodified. Open-source logos come from pinned CC0 collections and the CNCF; each product is listed with the licence read from its own repository. Logos and names are their owners' trademarks, used to name the products.

Left out of the Open source pack

Their licences are not OSI-approved (read 2026-11-20). They can come back later in a separate "source available" pack if wanted.

Keyboard

Behaviour

  • Changing the pack renames and re-icons blocks; the file keeps roles, so nothing moves and nothing is lost.
  • A block whose role has no product in the chosen pack shows the generic line icon and role name.
  • A custom block takes any name and a line icon, for things no catalog has.
  • Nothing blocks: a hint is a flag and a pill on the block, never a dialog.

Still open

  • The repository's licence.
  • A trademark check on the name (Archboard is a working name) before any public launch.
  • Everything else is decided: SPEC section 12.
